Supply Chain Data Model

Overview

SCO provides an out-of-the-box canonical data model focused on common supply chain entities and relationships. The model can be extended with additional attributes and objects to support industry-specific requirements and use cases, from high-level supply chain visibility to detailed operational data. Full APIs support the data model lifecycle, including retrieving schema information and extending the model programmatically.

Beyond SCO Workbench

SCO Workbench covers common data model tasks. Some operations require working directly in SCO:

Complex class inheritance, indexes, triggers, or computed properties
Accessing system and internal classes beyond the supply chain data model
How to Use
1
Explore built-in objects
Browse the object list on the left to see the standard supply chain entities SCO provides.
2
Inspect attributes and relationships
Select an object to view its typed attributes and a relationship diagram showing how it connects to other objects.
3
Add custom attributes
Select any object and click the edit icon in the detail header to add attributes specific to your use case.
4
Create a custom object
Click + at the top of the object list to define a new object with your own attributes and structure.
Not sure where to start? Open the AI Assistant and describe your data requirements — it can suggest which objects to review or extend.
