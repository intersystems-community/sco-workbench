Analytics Cube

Overview

SCO provides a built-in analytics engine with tools to design analytics cubes, query and visualize cube data, and keep cube data synchronized with the underlying source data. The analytics engine operates directly on the SCO data model, eliminating the need for separate ETL or schema transformation. Analytics cubes also provide the foundation for defining and monitoring KPIs.

Learn the Concepts

New to cubes? Pick a question and the AI Assistant will answer it for your SCO instance.

Beyond SCO Workbench

SCO Workbench covers basic cube definitions. More advanced analytics capabilities are available directly in SCO:

Computed dimensions, custom member expressions, and complex hierarchies
Cube relationships, subject areas, and linked cubes across multiple objects
Direct MDX querying, pivot table configuration, and custom dashboards
Index configuration and cube rebuild scheduling for performance tuning
How to Use
1
Explore out-of-the-box cubes
SCO ships with a set of pre-built cubes for common supply chain analytics. Select any cube from the list on the left to inspect its dimensions and measures, and see how it is structured. Out-of-the-box cubes are read-only and cannot be edited.
2
Create a new cube
Click + in the left panel, give the cube a name, and select the SCO data object it will be built on. Add dimensions and measures to define the analytical structure. Use the AI Assistant for suggestions based on your use case.
3
Edit a saved cube
Select an existing cube from the left panel to update its dimensions or measures. Use the AI Assistant to help refine the structure or troubleshoot unexpected results in your dashboards.
Not sure which dimensions or measures to define? Ask the AI Assistant — describe the supply chain metric you want to track and it can suggest a cube structure.
