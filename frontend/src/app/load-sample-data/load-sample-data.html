Everything you build in the workbench - your data model, KPIs, analytics cubes and dashboards - rests on supply chain data held in your Supply Chain Orchestrator instance. How that data gets there is up to you: connect a source of your own from the Data Integration page, or start from one of the ready-made sample data sets on this page. This step is optional - if your instance already holds the data you care about, you can skip it entirely.

Sample data is the quickest way to have something real to work with. Each set is a small, self-contained supply chain - customers, suppliers, products, orders and the like - kept ready on the server. Pick a set below to read what it covers, then press Load to bring it into your instance.

Loading is safe to try. A sample set is added alongside whatever your instance already holds — nothing of yours is changed, emptied or overwritten, and loading the same set a second time does not duplicate it. Anything in a set that does not fit your instance is left out rather than forced in, and the summary after a load tells you what went in and what did not. A large set can take a few seconds.
