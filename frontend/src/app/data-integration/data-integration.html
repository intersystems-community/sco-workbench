Data Integration

Overview

SCO provides a robust, industry-proven integration engine with out-of-the-box support for a wide range of integration adapters, as well as the ability to create custom adapters. Its powerful DTL engine supports complex data mapping and transformation, while its scalable messaging architecture enables SCO to handle complex integration requirements using standard capabilities or custom integration solutions.

Beyond SCO Workbench

SCO Workbench only showcase a few common integration configurations. More advanced scenarios require working directly in SCO:

Other data sources, such as other DBMS, message queues, streaming data, etc.
Complex transformation logic which involves custom logic or rules, or multiple data sources
Scheduling, monitoring, and upgrading deployed integrations
Advanced orchestration, error handling, and retry strategies via the SCO interoperability framework
How to Use
1
Create a new integration
Click + in the left panel to open the integration wizard. Follow the wizard steps to configure your source connection and field mappings. Use the AI Assistant at any point if you need guidance on connection settings or how to map your source data to SCO objects.
2
Edit a draft integration
Select an existing integration from the left panel to reopen the wizard and update its configuration. Use the AI Assistant to help refine mappings or troubleshoot issues with your source data.
Not sure how to structure your integration? Ask the AI Assistant — describe your source system and target data, and it can suggest an approach.
